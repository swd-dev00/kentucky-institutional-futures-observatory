# KIFO Roadmap

## Phase 0 — Foundation

- [x] Define project scope
- [x] Establish evidence-first design principles
- [x] Define architecture layers
- [x] Define evidence and indicator methodology
- [x] Define initial source strategy
- [x] Define canonical evidence record schema

## Phase 1 — First vertical slice

- [ ] Implement source registry
- [ ] Select a small authoritative source set
- [ ] Build retrieval/snapshot mechanism
- [ ] Normalize the first evidence records
- [ ] Add automated validation
- [ ] Produce one derived indicator
- [ ] Add tests for the transformation and validation rules

## Phase 2 — First public intelligence product

- [ ] Produce one dated KIFO research brief
- [ ] Publish methodology and limitations alongside the result
- [ ] Make the evidence trail inspectable
- [ ] Add a lightweight public visualization or dashboard

## Phase 3 — Observatory expansion

- [ ] Expand source coverage across the four initial domains
- [ ] Add temporal comparisons
- [ ] Add county/regional views where data supports them
- [ ] Add institutional profiles where evidence is sufficiently complete
- [ ] Establish recurring publication cadence

## Phase 4 — Institutional-grade system

- [ ] Automated source freshness monitoring
- [ ] Provenance-aware data versioning
- [ ] Quality/confidence scoring
- [ ] Reproducible analytical releases
- [ ] Public API or machine-readable release artifacts where appropriate
- [ ] Formal review process for published findings

## Definition of sturdy

KIFO is ready to be presented as a serious built system when Phase 1 is complete and Phase 2 has produced at least one reproducible public intelligence product.
